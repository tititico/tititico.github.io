# 二维码生成器

输入链接或任意文字，实时生成二维码，可下载 PNG / SVG。

## 使用

直接双击 `index.html` 用浏览器打开即可，无需安装任何东西、无需联网。

## 功能

- **实时预览**：输入即生成
- **纠错等级** L / M / Q / H —— 等级越高越耐污损遮挡，但图案越密
- **自定义**：前景色、背景色（支持透明）、白边宽度、导出尺寸（128–2048px）
- **导出**：PNG 下载、SVG 下载（矢量，可无损放大用于印刷）、复制图片到剪贴板
- **智能提示**：
  - 内容像网址但缺 `https://` 前缀时，提示并可一键补全
  - 前景/背景对比度过低、反色二维码、白边过窄时给出扫码失败风险警告
  - 内容超长时明确提示当前等级的容量上限
- 自动提升纠错等级：在不增大图案尺寸的前提下，尽量用更高的纠错等级
- 支持中文与 Emoji（UTF-8），最长约 2953 字节（纠错等级 L）

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 界面与交互（内嵌 CSS / JS） |
| `qrcode.js` | 二维码编码引擎，零依赖 |

`qrcode.js` 可独立使用（浏览器或 Node）：

```js
const qr = QRCode.generate('https://example.com', 'M');
// => { size, version, ecl, mask, modules: boolean[][] }

QRCode.toCanvas(qr, canvasEl, { size: 512, margin: 4, dark: '#000', light: '#fff' });
const svg = QRCode.toSvg(qr, { margin: 4, dark: '#000', light: 'transparent' });
```

## 实现说明

按 ISO/IEC 18004 标准实现，Byte 模式，支持版本 1–40：UTF-8 编码 → 比特流组装 →
分块 Reed–Solomon 纠错 → 交织 → 功能图形绘制 → 8 种掩码全部评分取最优。

不依赖任何第三方库或 CDN，内容全程留在本地浏览器，不会上传。

## 测试

引擎经第三方解码库 jsQR 反向验证：14 组内容（含中文、Emoji、超长文本、
WiFi 配置、带查询串的 URL）× 4 个纠错等级，共 56 例全部解码一致。
界面部分用 Puppeteer 驱动真实 Chrome 做了端到端回归（渲染、告警、
报错、透明背景、移动端布局、控制台零错误）。
