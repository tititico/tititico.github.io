# 三消小游戏（自定义图片版）

网页三消小游戏，可以上传自己的图片作为方块，也可以直接用默认水果开玩。

## 使用方法
1. 用浏览器打开 `index.html`。
2. （可选）选择 3–6 张图片；不选就用默认水果。
3. 点击「开始游戏」。

## 操作
- 点击两个相邻方块交换，或直接拖动 / 滑动方块（支持手机触屏）
- 无效交换会弹回并抖动提示
- 5 秒没操作会提示一步可走的位置

## 模式
- **无尽模式**：不限时间，随便玩
- **限时 60 秒**：倒计时结束后结算；一次操作里连消达到第 3 次及以上，每次 +2 秒；最后 10 秒倒计时变红；切到后台自动暂停

## 玩法与计分
- 三连 30 分，四连 60 分，五连及以上 100 分
- 连锁消除有连击倍数（第 n 次连锁 ×n）
- 没有可走的步时自动洗牌
- 最高分保存在本地浏览器，两种模式分开记录

## 文件说明
- `index.html`：主页面
- `style.css`：样式与动画
- `main.js`：游戏逻辑
- `mixkit-hard-pop-click-2364.wav`：消除音效
